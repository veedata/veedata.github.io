CoView is meant to be a dashboard for the KEM hospital for COVID-19 related information management system. The project provides a detailed view about the number of active COVID-19 cases in the hospital, the outcome with respect to age distribution chart and many other services that will allow the user to understand the trend for the hospital with ease. It allows new patients to be added; the status for any patient to be updated; reports to be modified or added. All of it can be done using CoView. Additionally, the app is built in such a fashion that it can be accessed through any device (mobile, tablet, laptop, PC) as long as it is connected to the internet.

CoView was designed and developed in association with KEM Hospital, Mumbai, by Dr. Irfan Siddavatam (HOD, IT), Ms. Ashwini Dalvi (Assistant Professor, IT), Mrs. Dipti Pawade (Assistant Professor, IT), Abhishek Patel, Aditya Panchal, Aditya Vedpathak, Apoorva Jain, Smit Moradiya and Viraj Thakkar (Students, LY, IT).
